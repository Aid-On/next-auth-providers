# Changelog

All notable changes to @aid-on/nextauth-providers will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-01-XX

### Added
- Initial release
- LINE provider for NextAuth.js
- Full TypeScript support
- Integration with @aid-on/auth-providers core library

### Features
- `LineProvider` - NextAuth.js compatible LINE OAuth provider
- Automatic profile mapping
- Session callback support
- JWT token handling

### Dependencies
- Requires NextAuth.js v4.0.0 or higher
- Uses @aid-on/auth-providers v0.1.0 (published on npm)
